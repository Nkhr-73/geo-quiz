# MapSprint

ゲーム風のマップクイズサイト。GitHub Pagesで公開するための初期スターターです。

## ファイル構成

- `index.html` — トップページ
- `quizzes.html` — クイズ一覧（次のPhaseで実装）
- `admin.html` — 管理者用クイズ作成画面（次のPhaseで実装）
- `css/style.css` — 共通デザイン
- `js/main.js` — ナビゲーションなどの処理
- `data/quizzes.json` — クイズデータ

## GitHub Pagesで公開

1. このフォルダ内のファイルをリポジトリのルートにアップロードします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. `Deploy from a branch` を選び、公開ブランチ（通常は `main`）と `/ (root)` を指定します。
4. 保存後、表示される公開URLを開きます。

この段階ではトップページと案内ページが動きます。クイズの保存・回答・地図操作はまだ未実装です。
